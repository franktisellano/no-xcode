# __DISPLAY_NAME__

iOS app (SwiftUI). Bundle id `__BUNDLE_ID__`, target/scheme `__APP__`.

## Never open Xcode

Everything is terminal-driven through `make`.

- `project.yml` is the source of truth; `__APP__.xcodeproj` is generated by XcodeGen and gitignored.
  Never edit the `.xcodeproj`. Change `project.yml`, then `make gen`. New `.swift` files under
  `__APP__/` are picked up on the next `make` with no project edits.
- Build output is summarized by `tools/xcb.sh`; the full log is `build/xcodebuild.log`.
- Trust `xcodebuild` over editor/SourceKit diagnostics.

## The loop

```sh
make test          # unit tests (Swift Testing, __APP__Tests/)
make run           # boot simulator, build, install, launch in test mode
make screenshot    # → build/screenshot.png (Read it to check the UI)
make tour          # screenshot tour → build/screenshots/Tour-NN-*.png
make screenshots   # whole UI suite + every screenshot → build/screenshots/
make device-run    # build + install + launch on a paired iPhone (DEVICE_NAME=... if several)
make testflight    # archive + upload (needs .asc.env)
```

Overrides: `SIM="iPhone 16"`, `OS=26.0`, `APPEARANCE=dark`, `DEVICE_NAME="..."`.

## Rules for changes

- **UI changes:** verify by looking. `make run && make screenshot`, then Read the PNG. For screens
  past launch, add a step to `__APP__UITests/ScreenshotTourTests.swift` and run `make tour`.
- **Identifiers:** give controls tests need a stable `.accessibilityIdentifier("kebab-id")` on the
  tappable element itself (not a container), and an accessor in `__APP__UITests/Screens.swift`.
- **Test mode:** `APP_TEST_MODE=1` (see `__APP__/TestMode.swift`) seeds deterministic in-memory data
  and stubs services. Keep it `#if DEBUG`. New external dependencies (network, auth, hardware)
  get a protocol with a stub chosen when `TestMode.isActive`.
- **Logic changes:** add or adjust tests in `__APP__Tests/`, run `make test`.
- **Secrets:** in gitignored `Secrets.xcconfig` (template `Secrets.example.xcconfig`), never in
  `project.yml` or Swift source.
- **Releases:** bump `MARKETING_VERSION` in `project.yml`; `make testflight` sets the build number.
